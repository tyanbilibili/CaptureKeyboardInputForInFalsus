# 监听按键

Windows 小工具：用组合键开关键盘监听，监听中按下 G / CapsLock 播放对应音效；还支持把按键与鼠标键改写后转发给系统。

## 功能
- **`Alt` + `Z`** 开关监听（窗口里也可手动开关，状态一目了然）
- 监听中按 **`G`** 播放 `g.mp3`、按 **`CapsLock`** 播放 `capslock.mp3`
- 短时间连按时**后按下的覆盖前面的**，不会叠着响；长按只触发一次
- 可选**按键改写**：`CapsLock→LShift`、`G→F`
- 可选**鼠标改写**：左键→`LShift`、右键→`Space`、中键→鼠标左键
- 改写**只在监听中生效**，暂停即恢复原样
- 键盘注入走**硬件扫描码**，DirectInput / Raw Input 的游戏也能识别

## 使用
1. 下载 `监听按键-v1.0.0.zip` 解压
2. 双击 `启动.bat`
3. 若游戏以管理员身份运行，请改用 `启动-管理员.bat`（会弹 UAC）

## 环境要求
- Windows（使用 Win32 API）
- Python 3（**纯标准库，不需要 pip 安装任何依赖**）
- 需要桌面会话
- 同时只允许运行一个实例

## 说明
- 注入的输入带有 `LLKHF_INJECTED` 标记，游戏与反作弊可以检测到。
  在带反作弊的在线游戏中使用可能违反用户协议并导致封号，请自行判断。
- **同时只允许一个实例**：重复双击会提示「程序已经在运行了」。
- 想换音效：直接替换同名的 `g.mp3` / `capslock.mp3` 即可。想换组合键、按键或改写映射，改 `key_listener.py` 顶部的 `COMBO_MODIFIERS` / `COMBO_KEYS`（开关组合键）、`SOUNDS`（音效文件）、`REMAP_PAIRS`（键盘改写）、`MOUSE_REMAP`（鼠标改写）。
- 某些安全软件会拦截全局钩子。如果状态显示「钩子安装失败」，或弹出「鼠标钩子安装失败」的提示，把本程序加入白名单后重试。
