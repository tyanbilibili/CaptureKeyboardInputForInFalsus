# 监听按键

一个 Windows 小工具：用组合键开启 / 关闭键盘监听，监听开启时按下 **G** 或 **CapsLock** 就播放文件夹里对应的音效。

短时间连按多次时，**后按下的音效会打断并覆盖前面的**，不会叠在一起响。

## 快速开始

下载所有code文件。双击 **`启动.bat`** 即可（会用 `pythonw` 静默启动，不弹黑窗口）。

也可以在命令行运行：

```bat
cd /d "路径\监听按键"
python key_listener.py
```

## 操作方式

| 操作 | 结果 |
| --- | --- |
| `Ctrl` + `Alt` + `G` | 开启 / 关闭监听（可随时切换） |
| `G` | 播放 `g.mp3`（仅在监听开启时） |
| `CapsLock` | 播放 `capslock.mp3`（仅在监听开启时） |

打开程序时**默认就是监听状态**，窗口上的圆点是绿色的「监听中」，变灰即「已暂停」。

窗口里还可以：

- 点按钮手动开启 / 暂停监听；
- 勾选 **屏蔽 CapsLock 本身的大小写切换** —— 勾上后按 CapsLock 只播音效，不再切换大小写；
- 在「最近触发」里看到最近一次播放的音效名和时间。

## 行为细节

- **一次按下只播一次**：长按 G 不会连续刷音效，系统产生的自动重复已被过滤。
- **后按覆盖前**：新音效一开始，上一个立刻停止（底层是「先关掉旧播放器，再打开新的」）。
- **组合键不会误触发音效**：按住 `Ctrl`+`Alt` 再按 `G` 时只切换监听状态，不播放 `g.mp3`。
- 监听关闭时，按 G / CapsLock 完全无反应，也不会影响系统本身的行为。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `启动.bat` | 双击启动（优先 `pythonw` / `pyw` / `py`） |
| `key_listener.py` | 主程序：小窗口 + 全局键盘钩子 |
| `key_logic.py` | 按键判定逻辑（纯 Python，可单独测试） |
| `audio_player.py` | 用 Windows MCI 播放 mp3，负责「覆盖」 |
| `keyhook.py` | 全局低级键盘钩子（`WH_KEYBOARD_LL`） |
| `selfcheck.py` | 自检脚本 |
| `g.mp3` / `capslock.mp3` | 音效文件 |

## 自检

```bat
python selfcheck.py            :: 全部检查（会出声）
python selfcheck.py --no-audio :: 跳过会出声的部分
python key_listener.py --smoke :: 只把窗口拉起来跑约 2 秒，确认能正常启动
```

覆盖：按键逻辑、音频覆盖播放、全局钩子是否真能收到按键，以及「按 G 真的会触发播放」的端到端链路。

## 说明与排错

- **零第三方依赖**：只用 Python 标准库 + `ctypes` 调 Windows 自带接口，不需要 `pip install` 任何东西。
- **只支持 Windows**（用到了 Win32 API）。
- **必须是有桌面会话的用户下运行**，全局钩子才能拿到按键。
- **同时只允许一个实例**：重复双击会提示「程序已经在运行了」。
- 想换音效：直接替换同名的 `g.mp3` / `capslock.mp3` 即可；想换按键或组合键，改 `key_listener.py` 顶部的 `SOUNDS` 和 `key_logic.py` 里的 `VK_G` / `VK_CAPITAL`。
- 某些安全软件会拦截全局键盘钩子。如果状态显示「钩子安装失败」，把本程序加入白名单后重试。
