# 监听按键

一个 Windows 小工具：用组合键开启 / 关闭键盘监听，监听开启时按下 **G** 或 **CapsLock** 就播放文件夹里对应的音效。

短时间连按多次时，**后按下的音效会打断并覆盖前面的**，不会叠在一起响。

## 快速开始

双击 **`启动.bat`** 即可（会用 `pythonw` 静默启动，不弹黑窗口）。

如果想在游戏里用、而那个游戏是以管理员身份运行的，请改用 **`启动-管理员.bat`**（会弹 UAC），原因见下文「在游戏里用」。

也可以在命令行运行：

```bat
cd /d "路径\监听按键"
python key_listener.py
```

## 操作方式

| 操作 | 结果 |
| --- | --- |
| `Alt` + `Z` | 开启 / 关闭监听（可随时切换） |
| `G` | 播放 `g.mp3`（仅在监听开启时） |
| `CapsLock` | 播放 `capslock.mp3`（仅在监听开启时） |

打开程序时**默认就是监听状态**，窗口上的圆点是绿色的「监听中」，变灰即「已暂停」。

窗口里还可以：

- 点按钮手动开启 / 暂停监听；
- 勾选 **屏蔽 CapsLock 本身的大小写切换** —— 勾上后按 CapsLock 只播音效，不再切换大小写；
- 勾选 **按键改写：CapsLock→LShift、G→F** —— 把这两个键换成别的键再送给系统（见下文）；
- 勾选 **鼠标改写：左键→LShift、右键→Space、中键→左键** —— 把鼠标按键换成别的键再送给系统（见下文，**勾之前请先读一遍**）；
- 在「最近触发」里看到最近一次播放的音效名和时间。

## 行为细节

- **一次按下只播一次**：长按 G 不会连续刷音效，系统产生的自动重复已被过滤。
- **后按覆盖前**：新音效一开始，上一个立刻停止（底层是「先关掉旧播放器，再打开新的」）。
- **组合键不会误触发音效**：按住 `Alt` 再按 `Z` 时只切换监听状态，不播放任何音效。
- 监听关闭时，按 G / CapsLock 完全无反应，也不会影响系统本身的行为。

## 按键 / 鼠标改写（可选）

窗口里有两个**默认关闭**的改写开关，作用都是「把源按键换成别的键，再送给系统」：

### 按键改写：CapsLock→LShift、G→F

| 你按下的 | 系统收到的 |
| --- | --- |
| `CapsLock` | `LShift`（左 Shift） |
| `G` | `F` |

### 鼠标改写：左键→LShift、右键→Space、中键→鼠标左键

| 你按下的 | 系统收到的 |
| --- | --- |
| 鼠标左键 | `LShift`（左 Shift） |
| 鼠标右键 | `Space`（空格） |
| 鼠标中键 | 鼠标左键（一次真正的点击） |

> ⚠️ 鼠标改写是**替换**而不是叠加：勾选后**鼠标左键不再点击、右键不再弹菜单、中键也不再是自动滚动**。
>
> **不过中键变成了左键，所以你不会失去点击能力**：
> - 想点击时，**按鼠标中键**即可 —— 它发出的就是一次真正的左键点击，能点按钮、点复选框、能拖拽，也能直接点这个窗口来取消勾选；
> - 这样就不必依赖键盘救场了。
>
> 若中键不好按（有些滚轮的按压很硬），还有两条退路：
> 1. 按 **`Alt + Z`** 暂停监听 —— 鼠标立刻恢复原样；
> 2. 用键盘 **`Tab`** 把焦点移到复选框，再按 **空格** 取消勾选。

两个开关共同的要点：

- **只在「监听中」生效**：监听一暂停，所有按键 / 鼠标立刻恢复原样。
- 改写时原始按键会被吞掉（`CapsLock` 因此不再切换大小写；此时「屏蔽 CapsLock 大小写切换」会自动置灰，因为它已无意义）。
- **音效照常播放**：按 `CapsLock` / `G` 仍然会响对应的 mp3，改写只影响「送给系统的那一次按键」。
- 按下和松开是成对改写的，不会出现目标键卡住；中途取消勾选时也会补发一次抬起。
- 「中键→左键」注入的那个左键带**防递归标记**，不会被「左键→LShift」再改写一遍，所以它始终是一次真正的左键点击。
- 组合键 `Alt + Z` 判断的是**改写前**的按键，所以开着重写也能正常开关监听。
- 对普通程序（浏览器、编辑器、多数游戏）有效；以管理员权限运行的程序可能收不到改写后的输入（见下文）。

## 在游戏里用

要让改写送进游戏，注入的按键必须**符合游戏读键盘的方式**。这一点之前踩过坑，现在已经修好：

| 谁怎么读键盘 | 我们怎么发 | 结果 |
| --- | --- | --- |
| 普通窗口程序、`GetAsyncKeyState` | 以前只发**虚拟键码** | ✅ 一直正常 |
| DirectInput / Raw Input 的**游戏** | 上面那种发法 | ❌ 游戏收不到（**曾经的问题**） |
| DirectInput / Raw Input 的**游戏** | 现在改用**硬件扫描码** | ✅ 正常 |

原因是 DirectInput 系列只认**物理扫描码**——微软文档原话：键盘数据 "refers **not to virtual keys but to the actual physical keys — that is, the scan codes**"。所以 `send_key()` 现在用 `KEYEVENTF_SCANCODE` + `MapVirtualKey` 发扫描码。

**鼠标那组为什么一直没事**：鼠标事件不存在虚拟键码 / 扫描码之分，游戏读的是按钮标志位——所以「中键→左键」当时就有效。这也正是「看起来只有鼠标那条生效」的原因。

如果游戏里仍然没反应，按这个顺序排查：

1. **游戏是不是以管理员身份运行？**（带反作弊的网游基本都是。）
   Windows 的 **UIPI** 会拦住「低权限进程 → 高权限进程」的输入注入。请改用 **`启动-管理员.bat`**，让本程序和游戏处于同一权限级别。
2. **游戏是不是有反作弊？**（Easy Anti-Cheat / BattlEye / Vanguard / XignCode 等。）
   这类组件会在内核层拦截、丢弃「看起来不像真人」的输入。**这种情况本工具没有（也不打算有）绕过的办法**——见下面的提醒。
3. **是不是按得太快？** 有些游戏按帧轮询输入，瞬间的 down→up 会被漏掉。手动按慢一点试试。

> ⚠️ **使用提醒**：注入的输入带有 `LLKHF_INJECTED` 标记，游戏与反作弊**可以检测到**。在带反作弊的在线游戏中使用可能违反用户协议并导致封号，请自行判断。本工具更适合**单机游戏、个人按键习惯调整、无障碍用途**等场景。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `启动.bat` | 双击启动（优先 `pythonw` / `pyw` / `py`） |
| `启动-管理员.bat` | 以管理员身份启动（游戏以管理员运行时用，会弹 UAC） |
| `key_listener.py` | 主程序：小窗口 + 全局输入钩子 |
| `key_logic.py` | 按键判定逻辑（纯 Python，可单独测试） |
| `audio_player.py` | 用 Windows MCI 播放 mp3，负责「覆盖」 |
| `keyhook.py` | 全局低级键盘 / 鼠标钩子（`WH_KEYBOARD_LL` + `WH_MOUSE_LL`） |
| `selfcheck.py` | 自检脚本 |
| `g.mp3` / `capslock.mp3` | 音效文件 |

## 自检

```bat
python selfcheck.py            :: 全部检查（会出声）
python selfcheck.py --no-audio :: 跳过会出声的部分
python key_listener.py --smoke :: 只把窗口拉起来跑约 2 秒，确认能正常启动
```

覆盖：按键逻辑、音频覆盖播放、全局钩子是否真能收到按键、**注入的按键是否真的带硬件扫描码**（游戏能不能认的关键）、按键改写是否真的把 G 变成了 F、鼠标改写是否真的把右键变成 Space / 中键变成左键（而且注入的左键不会被二次改写），以及「按 G 真的会触发播放」和 `Alt+Z` 开关的端到端链路。

## 说明与排错

- **零第三方依赖**：只用 Python 标准库 + `ctypes` 调 Windows 自带接口，不需要 `pip install` 任何东西。
- **只支持 Windows**（用到了 Win32 API）。
- **必须是有桌面会话的用户下运行**，全局钩子才能拿到按键。
- **同时只允许一个实例**：重复双击会提示「程序已经在运行了」。
- 想换音效：直接替换同名的 `g.mp3` / `capslock.mp3` 即可。想换组合键、按键或改写映射，改 `key_listener.py` 顶部的 `COMBO_MODIFIERS` / `COMBO_KEYS`（开关组合键）、`SOUNDS`（音效文件）、`REMAP_PAIRS`（键盘改写）、`MOUSE_REMAP`（鼠标改写）。
- 某些安全软件会拦截全局钩子。如果状态显示「钩子安装失败」，或弹出「鼠标钩子安装失败」的提示，把本程序加入白名单后重试。
